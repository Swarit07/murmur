Style

How Murmur writes in each kind of app. It looks at the app you’re typing in and uses the matching style.

Casual

Excited!

Auto cleanup

How much Murmur tidies what you said before it types. Applies to every style.

You said “um so I think we should uh, no wait, let’s ship Friday”
None
Exactly what you said, word for word. um so I think we should uh, no wait, let’s ship Friday
Light
Adds punctuation and drops filler words. So I think we should, no wait, let’s ship Friday.
Medium
Also resolves the corrections you make mid-sentence. Let’s ship Friday.
